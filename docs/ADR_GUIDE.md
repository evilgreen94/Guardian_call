# ADR Guide

Create an ADR when a decision changes the architecture, authority model, privacy model, risk semantics, deployment model or major dependency.

Do not create an ADR for trivial implementation details.

## Template

```markdown
# ADR-XXX — Title

## Status
Proposed / Accepted / Rejected / Superseded

## Context

## Decision

## Why

## Alternatives considered

## Consequences

## Revisit when
```

# Seven-Day Delivery Plan

## Day 1 — Consolidation
Goal: Browser → canonical M0 → real SSE → minimal visualizer.

Done when:
- text can be submitted in browser;
- canonical M0 executes;
- real events appear in browser;
- all M0 tests remain green.

## Day 2 — Multi-turn
Goal: one call session accumulates evidence and risk evolves visibly.

Done when:
- turns belong to one session;
- risk transitions are explainable;
- legitimate scenario does not become falsely CRITICAL;
- visualizer shows timeline.

## Day 3 — Audio
Goal: controlled audio reaches existing semantic pipeline.

Preferred:
- microphone or audio file;
- transcription/semantic extraction;
- no Android dependency.

## Day 4 — UX / Visualizer
Goal: make the working demo legible and memorable.

Focus:
- brutalist retro visual language;
- event movement;
- Canary boundary;
- clear user warning;
- no ornamental dashboard clutter.

## Day 5 — Trusted Circle
Goal: policy-controlled critical escalation.

Done when:
- Canary authorizes notification;
- real `TRUSTED_CONTACT_NOTIFIED` event occurs;
- second UI/contact panel reacts.

## Day 6 — Hardening / Cloud
Goal:
- four scenarios reliable;
- tests;
- Docker;
- Cloud Run;
- logs/evidence.

No feature additions.

## Day 7 — Submission
Goal:
- freeze code;
- 4-minute video;
- architecture diagram;
- README;
- Devpost copy;
- screenshots;
- final reproducibility check.

Absolutely no new features.
